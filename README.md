# BuildinZ — Neon Heights concept lab (v0.1)

An early interactive prototype for **BuildinZ**, a proposed Polygon-based architectural NFT collection. Explore Neon Residences' three permanent-style evolution stages, simulate BRICK upgrade costs, and test completing a five-building neighborhood set.

## Live demo
When GitHub Pages is enabled for this repository, the demo will be available at:
https://hubcityhubcity.github.io/buildings/

To enable Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Important: simulation only
- NFT ownership, staking, BRICK balances, rewards, and evolution costs are **simulated** in the browser.
- There are **no real blockchain transactions, no wallet connections, no real token, and no investment returns** here.
- Simulated building stage is stored in the local browser and can be reset. Actual irreversible on-chain evolution is not built yet.
- Artwork is conceptual; designs, economic rules, and future features remain subject to production, security review, and legal review.
